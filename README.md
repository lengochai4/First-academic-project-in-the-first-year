# Saigon Travel Guide

A first-year academic project designed to introduce attractions, local cuisine, and cafes across Ho Chi Minh City (Saigon), Vietnam.

---

## Project Structure

```text
First-academic-project-in-the-first-year/
│
├── index.html                  # Main homepage (Entry point)
│
├── pages/                      # Sub-pages
│   ├── aboutus.html            # About the project & team
│   ├── drink.html              # Cafes and beverage spots by district
│   ├── food.html               # Local restaurants and food spots by district
│   ├── login.html              # Admin login & post submission portal
│   ├── nextstep.html           # Food & Beverage gateway portal
```

---

## How to Open the Website

Double-click or open the [`index.html`](index.html) file in the root folder with any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).

---

## Technologies Used

- **HTML5**: Semantic web structure.
- **CSS3**: Flexbox, CSS Grid, custom scrollbars, transitions, and responsive layout.
- **Vanilla JavaScript**: DOM manipulation, automated slideshow, and interaction handling.
